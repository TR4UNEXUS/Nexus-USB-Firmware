# Contributing

Help building Nexus is welcome. Code changes, testing, clear bug reports and better build instructions all help.

For a bug report, include the Nexus version, Switch firmware version, what you were trying to do, and the steps that reproduce it. For USB problems, add the drive model, filesystem, cluster size and how it is connected. Remove private information from logs before posting them.

Keep pull requests focused. Explain the problem, the change and how you tested it. Say whether testing was on a PC or on a Switch; a passing host test does not prove that hardware behaviour is correct. Preserve copyright notices and third-party licences.

Useful areas to help with include sleep and wake across different drives, installation to SD with USB connected, library recovery, network transfers and easier build setup. Please open an issue before starting a large redesign so we can agree on the direction.

Do not include console keys, tickets, certificates, account credentials, game content or personal device backups in a contribution.
